🌤️ WheatherApp - Application Météo en React Native

📝 Description
* WheatherApp est une application mobile moderne développée avec **React Native** et **Expo**.
Elle permet aux utilisateurs de consulter les prévisions météo en temps réel en communiquant avec une API de services météorologiques.

🚀 Fonctionnalités
* Affichage en temps réel : Récupération des données météo actuelles via API.
* Interface intuitive : Affichage clair des températures et des conditions climatiques.
* Localisation : Affichage de la météo basée sur la ville choisie par l'utilisateur.
* Architecture propre : Utilisation de TypeScript pour un code robuste et maintenable.

🛠️ Technologies utilisées
* Framework : React Native (Expo Go)
* Langage : JavaScript / TypeScript
* API : Intégration d'une API météo (OpenWeatherMap ou équivalent)
* Outils : Node.js, npm

## ⚙️ Installation
1. Clonez le dépôt.
2. Installez les dépendances :
   ```bash
   npm install
3. Lancez l'application :
   ```bash
   npx expo start
